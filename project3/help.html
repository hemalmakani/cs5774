THE PLAYBOOK

A little help for game day.

How this prototype works, and what the numbers mean.

Explore as Alex

This is a coursework prototype of Fantasy Manager, using fictional players and a fixed Week 7 scenario. Alex is a demonstration account. There is no sign-in, real league membership or live data connection.

Build a valid lineup

Open a team and choose Edit lineup. Select a bench player, choose an eligible slot, and use Move player. The displaced starter goes to the bench. Undo reverses your last move. Cancel discards all unsaved changes.

You need nine starters with no bye-week players before saving. FLEX accepts RB, WR or TE. Questionable players may start, but an amber label keeps their availability visible.

Understand scoring

Full PPR awards one point per reception; Half PPR awards half a point; Standard awards no reception points. For the fictional data, Half PPR subtracts 0.5 times each player’s sample reception estimate from Full PPR, and Standard subtracts the full reception estimate.

All projections are illustrative. They are not predictions for real NFL players. QB means quarterback; RB, running back; WR, wide receiver; TE, tight end; DST, defense and special teams; K, kicker.

Search and compare players

Type running backs in the header search box and choose Search to see three sample players. This is a simulated search; other phrases show a friendly no-results message.

In Player Stats, choose Watch to add a player to your watchlist. Choose Remove from watchlist to remove the player. Your choices stay in this browser. In Create a Team, change the scoring format to compare projected points and see a worked example.

Your data stays in this browser

Team names, roster choices, saved lineups and your watchlist use local browser storage. There are no accounts, analytics, cookies or external requests from the prototype. Clearing site data removes saved work. If storage is unavailable, the app explains that it cannot save.

Use a local web server for consistent storage across pages. With Python installed, open a terminal in the project3 folder and run python3 -m http.server 8765, then open http://localhost:8765/index.html in your browser.

Keyboard & mobile access

Use Tab to reach links and controls, Enter or Space to activate a button, and the arrow keys within select menus. A skip link jumps to the main content. On narrow screens, navigation appears above the content and panels stack vertically.
